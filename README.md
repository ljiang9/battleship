# battleship 海战棋

10×10 海战棋,和"打猎-追踪" AI 对战。纯标准库,无依赖。

## 玩法

```bash
python -m battleship            # 交互对战
python -m battleship --demo     # AI 演示攻击
python -m battleship --selfplay # AI 自我对战
python -m battleship --seed 42  # 固定种子
```

- 你的舰队**自动布好**(标准舰队:5/4/3/3/2,共 17 格),省去手动布船的繁琐。
- 输入坐标射击,如 `B5`;`q` 退出。
- 棋盘符号:`.` 未射击 / `o` 未中 / `X` 命中。

## AI 说明

打猎-追踪 (hunt-target) 策略:

1. **打猎**:随机射击,直到命中;
2. **追踪**:命中后把四个相邻格加入队列,逐个试射;
3. 击沉一艘船后清空追踪队列,回到打猎。

## 设计取舍

- 船只允许相邻(不强制隔离规则),与常见休闲规则一致;README 如实说明。
- 自动布船保证无重叠;每局随机,可用 `--seed` 复现。

## 已知局限

- AI 是打猎-追踪,不是概率密度搜索——人类用"奇偶格"等策略可以赢它。
- 交互是行输入模式;无手动布船、无联机对战、无存档。
